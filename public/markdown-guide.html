1. Formatação de Texto Básica

Elemento Como Escrever (Sintaxe) Atalho Seguro Resultado Renderizado
Negrito **texto** Ctrl + B texto
Itálico *texto* Ctrl + I texto
Tachado / Riscado ~~texto~~ Alt + X texto
Destaque (Marca-texto) ==texto destacado== Alt + H texto destacado
Código Inline `const a = 1;` Ctrl + Shift + C const a = 1;

2. Listas e Checklists (Tarefas)

Item a Fazer - [ ] Comprar café Alt + L ou Ctrl + Enter
Comprar café
Item Concluído - [x] Ajustar deploy Alt + L
Ajustar deploy

3. Recursos Avançados

Elemento Como Escrever (Sintaxe) Atalho Seguro Resultado Renderizado
Tags Inline #urgente #roadmap Alt + T #urgente #roadmap
Wikilink (Link de Projeto) [[Anotações]] Alt + W 📄 Anotações
Link Externo [Google](https://google.com) Ctrl + K Google
Comandos Gerais Paleta de busca rápida Ctrl + / ou Alt + K Abre a paleta de comandos
Imagens / Anexos ![[foto.png]] ou ![[foto.png|200]] Ctrl + V (Colar) Exibe a imagem com lightbox interativo ao clicar
Callout de Informação > [!info] Dica Alt + I
ℹ️ Informação
Callout de Alerta > [!warning] Cuidado Alt + A
💡 Cuidado
Comentário Oculto %% apenas no editor %% - (Oculto no quadro, visível apenas na edição)
Linha Divisória --- Alt + D
